OpenAI has started selling Codex Micro, a compact keypad built with specialty keyboard maker Work Louder for people using ChatGPT Codex and related agentic coding workflows.

The device is positioned less like a general keyboard and more like a desktop controller for AI-assisted development. OpenAI's product page describes six agent keys that use RGB lighting to show whether a Codex task is idle, thinking, running, waiting or done. It also lists command keys for actions such as accept, reject, push-to-talk and starting a new chat, plus a joystick for launching common Codex workflows and a dial for changing reasoning level.

Work Louder's own product page says Codex Micro has 13 mechanical switches, one touch sensor, a rotary encoder and a planar joystick. It supports Bluetooth and USB-C, works with Mac and Windows, and ships with a Codex icon keyset. The page currently marks the limited run as sold out.

Independent coverage frames the release as OpenAI's first branded physical product, with Mashable reporting a $230 price and TechCrunch describing hands-on use of a test unit. TechCrunch found the device more useful after programming keys to specific ChatGPT sessions, while noting that the learning curve and narrow audience may limit its appeal.

The launch is small in scale, but notable because it turns agent supervision into a physical interface. For developers experimenting with multiple coding agents, Codex Micro is an early test of whether dedicated controls can reduce tab switching and make agent state easier to monitor.
