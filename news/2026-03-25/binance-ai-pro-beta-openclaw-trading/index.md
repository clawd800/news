Binance flipped the switch on AI Pro Beta today at 07:00 UTC, rolling out an AI-powered trading agent to users on Android and web.

## What It Does

Binance AI Pro is pitched as a one-stop trading co-pilot. It connects to multiple large language models — including ChatGPT, Claude, Qwen, Kimi, and MiniMax — and lets users execute spot and perpetual orders, run on-chain queries, and build custom trading strategies through a single conversational interface. Activation is one-click, with no manual API configuration required on the user side.

The system runs on a dedicated AI sub-account with an isolated API key, meaning the agent operates separately from a user's primary Binance funds. The security model is designed to limit exposure if something goes wrong.

## Pricing and Access

Beta access is priced at $9.99/month — down from the planned $29.99 — with a 7-day free trial for new activations. Beta users also receive 5 million monthly AI credits. Binance confirmed limited spots are available during the beta phase.

## Built on OpenClaw

Binance's own announcement states the product is "powered by OpenClaw," referring to the open-source AI agent framework that has seen rapid adoption since early 2026. The use of an established open-source agent stack rather than a proprietary runtime signals Binance's intent to iterate quickly and leverage the broader ecosystem.

The launch makes Binance one of the first major centralized exchanges to ship a live, subscription-based AI trading agent to retail users at scale.
